# GuardNet برای اندروید

اپلیکیشن اندروید GuardNet: همان حساب و همان قابلیت‌های نسخه‌ی وب، در یک برنامه‌ی
مستقل با آیکون، نوتیفیکیشن لینک‌ها و رفتار درست در حالت پس‌زمینه.

## پشتیبانی

| نسخه‌ی اندروید | API | وضعیت |
|---|---|---|
| ۵.۰ تا ۹ | 21 تا 28 | پشتیبانی می‌شود |
| ۱۰ تا ۱۶ | 29 تا 36 | پشتیبانی می‌شود |

- `minSdk = 21` (اندروید ۵.۰). روی اندروید ۴ و پایین‌تر، WebView داخلی مرورگر
  Chromium-محور نیست و قابل به‌روزرسانی هم نیست، بنابراین سایت React/Vite
  روی آن اجرا نمی‌شود؛ به همین دلیل پشتیبانی از آن نسخه‌ها ممکن نیست.
- برای تماس تصویری/صدا، **Android System WebView** باید به‌روز باشد
  (نسخه‌ی ۱۰۰ به بعد). از Play Store می‌شود آن را آپدیت کرد:
  `Play Store > Android System WebView > Update`.
- `targetSdk = 34` مطابق الزامات فعلی Google Play.


نصب روی نسخه‌های قدیمی‌تر: تنظیمات > امنیت > «نصب از منابع ناشناس» را برای
مرورگر مربوطه روشن کنید، یا فایل را کپی کنید و از فایل‌منیجر باز کنید.

حداقل مجوزها: دوربین و میکروفون (فقط هنگام تماس، با اجازه‌ی خود کاربر)،
دسترسی به اینترنت و ذخیره‌ی فایل‌های دانلودی. برنامه هیچ داده‌ای جمع‌آوری یا
ارسال نمی‌کند و فقط به `` وصل می‌شود.

## قابلیت‌ها

- ورود با حساب موجود GuardNet، بدون تغییر رمز.
- تماس صوتی و تصویری، ارسال عکس و فایل، پشتیبانی از پوشه با انتخاب‌گر فایل سیستم.
- لینک‌های `guardnet://` مثل نسخه‌ی ویندوز: پشتیبانی از باز کردن مستقیم یک
  گفتگو از مرورگر یا از اپ دیگری.
- نمایش در RTL با راست‌چین کامل، انتخاب متن، منوی فارسی مرورگر داخلی.
- تایمرها و WebRTC در چرخش صفحه قطع نمی‌شوند (تغییر orientation بازسازی
  WebView نمی‌کند).
- بازگشت به عقب مثل مرورگر؛ دوبار زدن دکمه‌ی بازگشت برنامه را می‌بندد.
- دانلود فایل از داخل گفتگو با DownloadManager.

نکته‌ها:

- **اشتراک صفحه در اپ اندروید پشتیبانی نمی‌شود**؛ WebView اندروید
  `getDisplayMedia` ندارد. در تماس موبایل، اشتراک صفحه از خودِ اپ‌های دیگر
  (مثلاً Meet/Zoom) انجام می‌شود.
- برای بهترین کیفیت صدا، اپ می‌تواند از طریق لینک داخلی
  `guardnet://audio/on` به حالت مکالمه برود (این قابلیت در نسخه‌ی وب
  استفاده می‌شود).

## ساخت

```bash
# نیازمندی‌ها: JDK 17 و Android SDK (platform 34 + build-tools 34.0.0)
./gradlew assembleRelease      # APK
./gradlew bundleRelease        # AAB برای Play Store
```

خروجی: `app/build/outputs/apk/release/GuardNet-release.apk`.

### امضای نسخه‌ی release

کلید امضا هرگز در git نیست. فایل `keystore.properties` (خارج از مخزن) مسیر و
رمزها را به Gradle می‌دهد:

```
storeFile=keystore/guardnet-upload.jks
storePassword=...
keyAlias=guardnet
keyPassword=...
```

بدون این فایل، build با کلید debug امضا می‌شود (برای آزمایش) و برای انتشار در
Play یا برای به‌روزرسانی روی دستگاه‌های کاربر قابل استفاده نیست. اگر کلید را
گم کنید، امکان انتشار به‌روزرسانی وجود ندارد؛ یک کپی امن نگه دارید.

ساخت کلید جدید:

```bash
keytool -genkeypair -v -keystore keystore/guardnet-upload.jks -storetype PKCS12 \
  -alias guardnet -keyalg RSA -keysize 4096 -validity 10950
```

### نکته‌ی شبکه در build

بعضی شبکه‌ها `dl.google.com` را می‌بندند؛ به همین دلیل در `settings.gradle`
آینه‌های Google Maven (`maven.aliyun.com` و `mirrors.cloud.tencent.com`) قبل از
مخزن اصلی آمده‌اند. اگر شبکه‌ی شما به `dl.google.com` دسترسی دارد، می‌توانید
این خطوط را حذف کنید.

## ساختار

- `app/src/main/java/ir/guardnet/app/MainActivity.java`: WebView، مجوزها،
  ناوبری، دانلود، لینک‌های عمیق.
- `app/src/main/AndroidManifest.xml`: مجوزها، intent-filter لینک عمیق،
  جلوگیری از بازسازی WebView در چرخش.
- `app/src/main/res/xml/network_security_config.xml`: فقط HTTPS.
- عمداً هیچ کتابخانه‌ای (AndroidX یا غیره) استفاده نشده تا حجم APK کم و
  `minSdk 21` قابل حفظ بماند.

## امنیت

- فقط `` داخل WebView باز می‌شود؛ بقیه‌ی لینک‌ها به مرورگر یا
  برنامه‌ی مربوطه سیستم می‌روند.
- `intent://` فقط به‌صورت یک لینک ساده‌ی `http(s)` به مرورگر داده می‌شود و
  component/extraهای آن دور ریخته می‌شوند (جلوگیری از intent injection).
- `file://`، `content://`، `javascript:` و ترکیب HTTP با HTTPS مسدود است.
- کوکی‌های شخص ثالث غیرفعال است و پشتیبان‌گیری از داده‌های برنامه خاموش.
