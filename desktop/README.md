# GuardNet Desktop (Windows)

کلاینت دسکتاپ GuardNet برای ویندوز. یک پوسته‌ی سبک روی همان وب‌اپ سایت است، بنابراین
قابلیت‌های جدید بلافاصله از سرور می‌آید و نیازی به انتشار نسخه‌ی جدید نیست.

## پشتیبانی

| سیستم‌عامل | معماری | وضعیت |
|---|---|---|
| Windows 7 SP1 | 32 و 64 بیت | پشتیبانی می‌شود (نیازمند SP1 و وصله‌های به‌روز) |
| Windows 8 / 8.1 | 32 و 64 بیت | پشتیبانی می‌شود |
| Windows 10 / 11 | 32 و 64 بیت | پشتیبانی می‌شود |

- حداقل نسخه‌ی ویندوزی که در فایل‌های اجرایی اعلام شده `5.1` است، یعنی روی
  Windows 7 به بعد اجرا می‌شود.
- کتابخانه‌های لازم به‌صورت static پیوند داده شده‌اند؛ نیازی به نصب
  Visual C++ Redistributable نیست.
- Windows 7 بدون SP1 و بدون وصله‌های SHA-2 در حالت کلی اجرا نمی‌شود.
- نسخه‌ی `x64` روی ویندوز 64 بیتی، و نسخه‌ی `ia32` روی ویندوز 32 بیتی و همچنین
  روی ویندوز 64 بیتی (از طریق WOW64) کار می‌کند.

تشخیص معماری: در ویندوز `Win + Pause` بزنید؛ مقابل `System type` نوشته
`64-bit` یا `32-bit operating system`.

نصب‌کننده per-user است و UAC لازم ندارد، پس روی اکانت‌های استاندارد هم نصب می‌شود.
مسیر نصب پیش‌فرض: `%LOCALAPPDATA%\Programs\guardnet`.
روی میزکار و منوی استارت شورتکات ساخته می‌شود. حذف برنامه از
`Settings > Apps` انجام می‌شود و اطلاعات ورود و تنظیمات کاربر را پاک نمی‌کند.

## قابلیت‌ها

- تماس صوتی و تصویری با همان کیفیت نسخه‌ی وب، از جمله اشتراک صفحه با
  پشتیبانی صدای تب/سیستم.
- ورود به حساب کاربری موجود GuardNet، بدون تغییر رمز یا نشست‌ها.
- میان‌بُر `guardnet://` برای باز کردن مستقیم یک گفتگو یا دعوت از مرورگر.
- بستن پنجره به‌جای خروج کامل (minimize to tray) و خروج از منوی tray.
- به‌خاطرسپاری اندازه/موقعیت پنجره، بزرگ‌نمایی و حالت fullscreen.
- باز کردن لینک‌های بیرونی در مرورگر پیش‌فرض، نه داخل پنجره‌ی برنامه.
- مدیریت مجوز دوربین، میکروفون، صدای صفحه و اعلان‌ها.

## نکته‌ها

- برنامه به اینترنت و دسترسی به `` نیاز دارد؛ بدون اینترنت فقط
  پوسته بالا می‌آید و محتوایی نمایش داده نمی‌شود.
- فایل‌ها امضای دیجیتال ندارند، پس SmartScreen ممکن است هشدار دهد
  (`More info > Run anyway`).
- برای اجرا روی ویندوز ۷ ممکن است لازم باشد درایور گرافیک و
  Windows Feature Experience Pack به‌روز باشد.

## توسعه و ساخت

```bash
npm install
npm start          # اجرا در حالت توسعه
npm run smoke      # تست خودکار راه‌اندازی (خروجی JSON در stdout)
npm run pack       # ساخت نصب‌کننده و نسخه‌ی پرتابل برای x64 و ia32
```

- `main.js`: پنجره، tray، مجوزها، deep link، تنظیمات پنجره و تست smoke.
- `preload.js`: پل امن بین رابط کاربری و لایه‌ی native.
- `electron-builder.yml`: تنظیمات بسته‌بندی، آیکون‌ها و اهداف NSIS/portable.
- `build/icon.ico`, `build/tray.png`: آیکون پنجره و tray.

آیکون‌ها به‌دلیل محدودیت `nativeImage` داخل `app.asar` خوانده نمی‌شوند و با
`extraResources` کنار فایل اجرایی قرار می‌گیرند.

نسخه‌ی Electron روی `21.4.4` قفل شده، چون آخرین نسخه‌ای است که از Windows 7
پشتیبانی می‌کند (Chromium 106). برای پشتیبانی از ویندوز جدیدتر می‌توان آن را بالا
برد، ولی سازگاری با ویندوز ۷ از بین می‌رود.

خروجی ساخت در `dist-desktop/` قرار می‌گیرد (در Git نیست). برای انتشار، فایل‌ها
در `frontend/dist/downloads/` روی سرور قرار می‌گیرند و از طریق

### تست smoke

```bash
electron . --smoke --smoke-json=out.json --smoke-out=shot.png
```

خروجی شامل نسخه‌ی Electron/Chromium، معماری، نسخه‌ی ویندوز، وضعیت
`desktopCapturer`، بارگذاری صفحه، دسترسی دوربین و تولید offer WebRTC است. اگر
`displayMedia.ok` نبود، اشتراک صفحه در آن دستگاه کار نمی‌کند.
